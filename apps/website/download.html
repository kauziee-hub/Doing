Requirements

Doing runs its AI on your computer, so the hardware decides how fast it is. It picks one of two setups automatically, and you can switch in Settings → Engine.

  • Windows 11, 64-bit. Other versions haven't been tested.
  • Memory: tested with 16 GB of RAM.
  • Internet for the one-time setup and, if you leave it on, a daily update check. Doing works offline after setup.
  • Audio: a microphone and speakers or headphones. Headphones keep your mic from picking up the other side.
  • Laptops: keep it plugged in during calls. On battery the graphics card slows down a lot.

Install

  1. Download the installer

    Use the button above. It's about 136 MB.

  2. Run it

    Double-click Doing-Setup-…-x64-unsigned.exe. If SmartScreen appears, check the file (next section), then choose More info → Run anyway. It installs for your user only; no admin rights are needed.

  3. Open Doing and press Set up

    The first screen shows your hardware and what will be downloaded. Press Set up Doing; progress is shown for each part and interrupted downloads resume.

  4. Add your documents (optional)

    Notes, specs, a job description or your résumé make answers specific to you. They are indexed on your PC.

  5. Start listening

    Press Start (or Ctrl Shift L) and confirm everyone has agreed to be transcribed.

Verify the download

Compare the file's SHA-256 with the one shown above. In PowerShell:

  1. Open PowerShell in your Downloads folder

    cd $env:USERPROFILE\Downloads
Get-FileHash .\Doing-Setup-*.exe -Algorithm SHA256

  2. Compare

    The Hash value must match the SHA-256 above exactly. If it doesn't, delete the file and download it again.

What the first run downloads

Everything comes from the projects' official sources and is checked against a published SHA-256 before it is used:

  • Answer engine: the Ollama runtime (1.6 GB) from GitHub. If you already have Ollama installed, Doing reuses it and its models.
  • Speech recognition: whisper.cpp from GitHub (685 MB with NVIDIA CUDA, 9 MB for the processor).
  • Speech model: Whisper from Hugging Face (574 MB or 190 MB).
  • Answer model: Qwen from the Ollama library (3.3 GB or 1.4 GB).

On a home connection the processor setup took about 17 minutes in our test.

Update

Doing 0.4.0 and later update themselves. Doing checks once a day and tells you when a new version is out. Open Settings → Updates and press Download and install: the installer comes from Doing's GitHub releases, is checked against its SHA-256, and Doing closes, updates and opens again. You can also press Check for updates there at any time.

Coming from Hirora (0.3.7 or older): quit Hirora (right-click the tray icon → Quit), download the installer above and run it once. It installs over the old version; your settings, documents and the downloaded models are kept. From then on, updates come from inside the app.

Release notes are in the changelog.

Uninstall

Windows Settings → Apps → Installed apps → Doing → Uninstall. Your data stays so a reinstall keeps your setup. To remove everything, also delete %APPDATA%\Hirora (settings, documents, history) and %LOCALAPPDATA%\Hirora (speech and answer models).
