Changelog

What's new

Every release of Doing, newest first. The full technical log is in the repository.

0.5.4

29 November 2026Latest
  • Continue through numbered questions and multi-select answers, with checked options preserved.
  • Recover from page changes before a click and wait for the next question to load.
  • Going Next keeps final assessment submission separate. Reload the browser companion once after updating.
  • Spotify song requests match close titles and check playback before saying a song is playing.

0.5.3

28 November 2026
  • Session app control: read accessible Windows app controls, click, type and scroll, with results checked after each operation.
  • Whole-page explanations scroll and combine sections without editing the page.
  • GPU thinking for difficult coding tasks and explicit “think carefully” requests.
  • Includes 0.5.2’s PC-wide file search, app launch, settings and recovery of profiles left in coding-tool containers.

0.5.1

27 November 2026
  • Scroll through long pages and answer questions one at a time.
  • Separate tab context and stronger “do not submit” checks.
  • Move files and folders to Windows Recycle Bin, with completion replies based on confirmed actions.

0.5.0

27 November 2026
  • Doing across the app, extension, GitHub repository and website.
  • Move and rename whole folders, with Undo.
  • Existing documents, settings and models migrate to Doing data folders.

0.4.2

27 November 2026
  • Corrected the browser panel's arrow icons and punctuation.
  • Code entry checks that a requested JavaScript function signature is preserved before replacing the editor.

0.4.1

27 November 2026
  • One assistant, clearer places to work: Assistant, Meetings, Browser, Library and History.
  • PC file tasks: chat, create, edit and organize files in a folder you allow, with a change list and Undo.
  • Chrome and Edge chat: ask about pages, fill forms, type code and continue through tasks from the side panel. Say when to submit in your message.
  • Work across up to eight allowed tabs. Removing one keeps the others available.
  • Shorter setup, cleaner screens and consistent Doing branding across the app, extension and website.

0.4.0

27 November 2026
  • Hirora is now Doing, with a new logo. Your settings, documents and downloaded models stay where they are.
  • Clearer sections: Meetings, Prep (your profile and documents), History and Settings.
  • Shorter texts everywhere.
  • Updates from inside the app: Settings → Updates checks for a new version and installs it in one click.

0.3.7

27 November 2026
  • Answer from the screen in one key. Ctrl+Shift+O (or the camera button on the overlay) reads the question on your screen and answers it, with nothing to type or paste. For a coding problem: the approach, the code and the complexity.
  • “Can you solve this?”, “here’s the problem” or “open the link I sent” now make Doing look at your screen.
  • Sharper screen captures, so small text on high-resolution laptops is read correctly.
  • Answers no longer show source markers like [S1] or the list of sources under them.

0.3.6

26 November 2026
  • Expand works again. It could think for over a minute and then show nothing.
  • “How did you build it?” gets a short walkthrough (about 100 words): the parts, what each is built with, and how the data moves through them, not just a list of tools.
  • Asking about a project by name finds that project’s notes first.

0.3.5

26 November 2026
  • A follow-up about one thing you’ve used (“random forest? what did you do with it?”) is answered from your own documents only; an example in Doing’s instructions could slip into answers.
  • “What do you know in ML?” lists methods and models, not web frameworks or cloud services.

0.3.4

26 November 2026
  • Answers that sound like you talking. Asked “what do you know in ML?”, Doing now gives the plain list, and a follow-up like “random forest? what did you do with it?” gets one or two sentences, not a story. Short answers are one to three spoken sentences, medium two to five; Expand still gives the long version.
  • On NVIDIA graphics cards, answers no longer stop mid-sentence when you’ve added a full résumé: the answer engine now has twice the room.
  • Fixed: after one over-long question, later answers could come back slow or empty until Doing was restarted.
  • Questions about your own work (“Did you write all this code yourself?”) no longer read the screen.

0.3.3

26 November 2026
  • More documents, still answers. Adding several documents next to a résumé could make every answer fail, because the prompt no longer fitted the local model. Doing now keeps the material it sends within the model's limit, résumé first, and retries with less if it ever overflows.
  • Screen reading no longer starts on everyday phrases like “Where do you see yourself in five years?” or “How would you improve it?”. It looks at the screen only when a question points at something shown.
  • Numbers in long document paragraphs stay intact (“0.25 s” was being split at the decimal point).

0.3.2

24 November 2026
  • In a room, too. Settings → Engine → Where the conversation is: on a call (as before), or in a room, where one microphone hears everyone and the questions it hears are answered as well.
  • Without headphones your microphone picks up the call; Doing no longer reads that copy as something you said.
  • Answers know which lines of the transcript are yours and which are the other side's.
  • An experimental live speech path with an end-of-turn model is included but switched off: in our tests it was accurate but not yet faster. It makes the installer about 28 MB larger.

0.3.1

22 November 2026
  • One assistant. The six modes are gone. Ask anything in your own words; Doing answers about you, writes code with tests, explains, or summarises the call as the question needs.
  • Reads the shared screen. When a question refers to something shown (“add RBAC to this”, “which of these routes…”), Doing looks at the monitor you're using and answers about what's on it. The picture stays in memory and goes only to the model on your PC.
  • Settings → Answers is down to length, language, tone and when to use the screen.

0.3.0

22 November 2026
  • Everything runs on your PC. Speech recognition and answers now always run locally. Cloud services, API keys and provider settings are gone.
  • One-click setup. On first launch Doing checks your hardware and downloads the right models, verifying every file. Interrupted downloads resume.
  • Sized to your PC. NVIDIA graphics cards with 6 GB or more get the fast setup; other PCs get smaller models that run on the processor.
  • Questions asked right after starting wait for the engine instead of failing.
  • A cleaner app: a shorter first-run guide and simpler settings.

0.2.4

22 November 2026
  • Answers start before the speaker finishes and appear as soon as they pause.
  • Live transcription with Whisper on the graphics card.
  • Questions that assume facts missing from your documents are answered honestly instead of invented.

0.2.3

  • Background talk in the room no longer triggers answers, while casual questions still do.
  • Answers read like a person explaining: connected paragraphs instead of bullet lists.

  • The main window is left out of screen shares too.
